# 阶段①审核记录

## 审核对象

`01-需求描述.md`：异构 SMMU 页表与统一 PASID 支持。

## Momus 返回结论

**条件通过；初步 Feature 分级通过。**

清晰性、验收场景和归档内容基本满足阶段①要求；需要统一待确认项的状态，避免候选实现提前成为硬性需求。

## 意见及修订

1. PASID 覆盖范围：已将“两类设备均使用同一 PASID”统一标为待确认，并同步修改功能目标及 AC1。
2. 接口兼容：删除“不要求原样复用”的确定性表述，统一为待用户确认现有接口签名和调用契约要求。
3. 设计与需求分离：将功能目标中的具体上下文结构改为可观察的按进程管理能力；候选结构保留在第5节。
4. 物理页表共享：区分“硬件允许共享”与“必须共享”的要求强度；AC2 中物理共享标为提议验收条件。

## 提交用户的确认事项

- 同一 PASID 是否覆盖 CPU 共页表与异构两类设备。
- 异构侧是否必须支持可恢复缺页；是否允许登记合法范围后按需填充页表。
- 是否必须兼容现有 SVA 接口，还是允许新增异构侧接口。
- 共享一份物理异构页表是否为硬性要求。

当前状态：按审核意见完成文档修订，原审核结论为条件通过；未将其改记为无条件通过，待用户确认上述边界后进入下一阶段。

## BTM 需求增补审核

用户新增要求：缓存失效尽量利用 SMMU BTM。

已增加 R10、功能目标6、AC9 和对应调研输入。Momus 增补审核结论：**通过，无必须修改项**。明确兼容时优先使用，不满足条件时回退；相同 PASID 不是 BTM 生效的充分条件；需分别核实标识、广播覆盖、完成保证和 ATS/ATC 维护。增补通过不表示前述未决事项已经用户确认。
