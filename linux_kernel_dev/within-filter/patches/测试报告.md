## 验证方法

测试脚本 `tests/test_within_filter.sh` 基于 `kmem:kmalloc` tracepoint。
通过 `tracefs` 接口设置和验证 `within` 过滤器。

test1 采用读/写双向对比：
- `within == "vfs_read"` + `dd if=/proc/self/status`（读路径）→ 应匹配
- `within == "vfs_read"` + `echo > /tmp/f`（写路径）→ 不匹配
- `within == "vfs_write"` + `echo > /tmp/f`（写路径）→ 匹配
- `within == "vfs_write"` + `dd if=/proc/self/status`（读路径）→ 不匹配
