# 隔离软件原型自审结论

后续 callback-runtime 阶段的实现/自审与最终 gate 见文末和 `08-SVA回调验证.md`；前部是第一阶段记录。

本记录仅适用于用户另行授权的隔离软件原型，不是完整 88-ID 生产特性的验收。没有创建 commit。

## 功能完整性

- 新增 conditional ops 槽、post-TLBI wrapper/关闭 stub 及单 SRCU 分发；同订阅先条件回调，再无条件 old。原 dispatcher 不变。
- 注册规则扩展到两个 TLB 槽与 range_start/end 互斥；双 TLB 槽可共存。
- SMMUv3 共享范围归一化，拆成 TLB-only、ATC-only；原合并 callback 依次调用二者。生产 domain allocation 仍选原 legacy ops。条件表及访问器仅 KUnit 可见。
- 外部测试通过窄 `mmu_notifier_test_alloc_mm()` 使用真实独立 mm；该入口仅 KUnit 编译和命名空间导出，不普遍导出 mm_alloc。
- 没有 provider、DT binding、寄存器读取、架构 TLBI 接入或生产条件模式激活。

## 并发与资源生命周期

新 dispatcher 只在一次 SRCU 读区间遍历原 list；对象和 ops 生命周期沿用现有 unregister 同步。不宣称 release 与两个回调互斥。

测试 subscriber 与 ops 存储在每用例 fixture 中，每次成功注册即记录 registered；per-case exit 先 unregister，再 mmput，最后 KUnit 自动释放存储。回调仅记录计数和参数，不等待、不睡眠。测试复用注册对象前已完成 unregister。

本原型没有静态 stub 或假设备命令调用，因此完整方案 G1–G4 的 stub 安装和保护析构框架不在此次实现内。SMMU 假对象只用于纯 size helper，不注册其 notifier，不调用 release/free。
