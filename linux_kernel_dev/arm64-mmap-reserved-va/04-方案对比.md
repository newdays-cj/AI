# 方案对比

| 方案 | 优点 | 缺点 |
|---|---|---|
| 每进程不可变占位VMA | 每mm/exec建立不可变占位，编号映射原子替换，munmap后重建；改造固定映射与继承维持隔离，可行 | 初始化、拆分、恢复和失败回滚复杂，每mm元数据开销较大。 |
| 全局不可变范围表 + 选址过滤 + VMA编号（推荐） | 无每mm占位开销，规则解除映射后保留，内核注册及DTS共用接口 | 需要覆盖固定地址及增长/移动入口，并处理文件专用选址验证。 |

选择第二方案。原回调通过任务局部上下文在公共空洞搜索中受编号范围约束，保留原对齐决策，不伪造MAP_FIXED。普通搜索过滤全部预留区，回调最终结果复核。详见05修订契约。
