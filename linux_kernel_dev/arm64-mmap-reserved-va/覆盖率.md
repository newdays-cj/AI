| 函数/路径 | 实测状态 | 证据及未覆盖边界 |
|---|---|---|
| reserved_va_register、freeze、check、vm_flags、map_flags、get_area、prepare、skip | ✅ | 核心文件100%行及100%分支，KUnit+真实mmap覆盖正常及错误边界 |
| DTS register_range、reserved_user_va_init | ✅功能、⚪编译器异常边 | 25/25行、21/22分支；最后分支为栈保护失败，不通过破坏内核栈触发 |
| mmap/直接插入/扩展/stack/brk新增检查 | ✅功能、⚪内部重复防御路径 | 新增执行行29/29；vm_end单独篡改须作为可执行用例覆盖，不能归入例外；其余经过调用链确认的前置校验后重复防御路径不宣称全覆盖 |
| mremap新增检查及编号继承 | ✅ | 固定双向/跨号失败哨兵、原地/自动/DONTUNMAP；原有函数全部错误路径并未穷尽 |

| 测试模块自身分配失败/线程创建失败 | ⚪ | 正常测试均成功；未注入内存耗尽，不能声明这些框架分支已执行 |

硬件例外、编译器生成异常边及原有mm函数未覆盖路径均明确列出；不宣称整个mm或全部修改函数历史分支100%。最终新增执行行：mmap29/29、关联分支25/32；mremap8/8、关联分支4/4。vm_end独立篡改BRDA:2962,0,3,6已命中。Momus⑨终审通过，接受其余已披露例外，不要求穷尽历史mm函数分支。
