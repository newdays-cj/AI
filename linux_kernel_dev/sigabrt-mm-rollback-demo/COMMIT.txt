    task: add experimental ARM64 thread-group checkpoint demo
    
    Add a privileged, cooperative, one-shot checkpoint interface for
    native ARM64 thread groups behind a default-off Kconfig option.
    
    Retain exiting original tasks so pthread joins can complete without
    losing their identities. On a default SIGABRT, remove newly created
    threads and restore the shared address space and original user contexts.
    Coordinate fork, exit, signals, ptrace and cgroup operations during the
    checkpoint lifecycle.
    
    Include KUnit admission tests and document the restricted resource model.
    Validated with enabled and disabled ARM64 builds, KUnit, and QEMU
    functional, fault-injection and lifecycle tests.
    
    Signed-off-by: Chen Jun <newdays-cj@live.com>
