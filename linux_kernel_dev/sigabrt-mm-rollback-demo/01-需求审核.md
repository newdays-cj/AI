# 阶段①需求审核

已调用 Momus 审核，结论：条件通过，Feature 分级合理。

审核指出的四项问题已在需求描述中修订：

1. 全局可写数据不一定属于匿名映射，改为明确覆盖所需私有映射。
2. 补充恢复失败时的可观察终止验收项 AC-08。
3. 以实际信号递送时选择的默认终止动作为触发条件，补充信号边界验收项 AC-09。
4. 明确工作流提交要求与上级工具规则的优先级，未经显式请求不创建 commit。

待用户确认首版范围，再进入阶段②调研。

## 多线程修订审核

用户明确要求 ARM64、多线程、一次性检查点，单线程建议已被替代。

再次调用 Momus，结论为条件通过。要求补齐全部存活线程参与、原任务/TID 保留、信号恢复、并发 SIGABRT、线程集合变化窗口、安全点与超时、失败退出及一次性生命周期语义。

已在需求文档“多线程补充语义”中给出待确认的建议定义。固定线程集合、安全点约束及这些新增语义尚未获用户确认，不能作为已经批准的实现范围。
