# SMMUv3 EVTQ TRACE_EVENT 实现方案

## 1. 详细设计

### 1.1 新增文件

#### `drivers/iommu/arm/arm-smmu-v3/trace.h`

```c
/* SPDX-License-Identifier: GPL-2.0 */
/*
 * ARM SMMUv3 trace support
 *
 * Copyright (c) 2026 OpenCloudOS / openEuler
 */

#undef TRACE_SYSTEM
#define TRACE_SYSTEM arm_smmu_v3

#if !defined(_TRACE_ARM_SMMU_V3_H) || defined(TRACE_HEADER_MULTI_READ)
#define _TRACE_ARM_SMMU_V3_H

#include <linux/tracepoint.h>

struct arm_smmu_device;

TRACE_EVENT(smmu_evtq_event,
    TP_PROTO(struct arm_smmu_device *smmu, u64 *evt),
    TP_ARGS(smmu, evt),
    TP_STRUCT__entry(
        __string(iommu, dev_name(smmu->dev))
        __field(u64, evt0)
        __field(u64, evt1)
        __field(u64, evt2)
        __field(u64, evt3)
    ),
    TP_fast_assign(
        __assign_str(iommu, dev_name(smmu->dev));
        __entry->evt0 = evt[0];
        __entry->evt1 = evt[1];
        __entry->evt2 = evt[2];
        __entry->evt3 = evt[3];
    ),
    TP_printk("%s evt: 0x%016llx 0x%016llx 0x%016llx 0x%016llx",
        __get_str(iommu),
        __entry->evt0, __entry->evt1,
        __entry->evt2, __entry->evt3)
);

#endif /* _TRACE_ARM_SMMU_V3_H */

/* This part must be outside protection */
#undef TRACE_INCLUDE_PATH
#undef TRACE_INCLUDE_FILE
#define TRACE_INCLUDE_PATH ../../drivers/iommu/arm/arm-smmu-v3/
#define TRACE_INCLUDE_FILE trace
#include <trace/define_trace.h>
```

### 1.2 修改文件

#### `drivers/iommu/arm/arm-smmu-v3/arm-smmu-v3.c`

**变更 1**：在 include 区域末尾添加：

```c
#include "trace.h"
```

**变更 2**：在 `arm_smmu_evtq_thread()` 中，`queue_remove_raw()` 成功后立即插入：

```c
// 当前代码 (L2054-2077):
do {
    while (!queue_remove_raw(q, evt)) {
        u8 id = FIELD_GET(EVTQ_0_ID, evt[0]);

        ret = arm_smmu_handle_evt(smmu, evt);
        if (!ret || !__ratelimit(&rs))
            continue;
        // ... dev_info() ...

// 修改后:
do {
    while (!queue_remove_raw(q, evt)) {
        u8 id = FIELD_GET(EVTQ_0_ID, evt[0]);

        trace_smmu_evtq_event(smmu, evt);  // ★ 新增

        ret = arm_smmu_handle_evt(smmu, evt);
        if (!ret || !__ratelimit(&rs))
            continue;
        // ... dev_info() ...
```

### 1.3 不改动的文件

- `arm-r-smmu-v3.c` — 不修改
- `arm-smmu-v3.h` — 不修改（不新增 EVT_ID_* 宏）
- `Makefile` — 不修改
- Kconfig — 不修改

## 2. 接口定义

| 接口项 | 定义 |
|--------|------|
| **Tracepoint 名称** | `arm_smmu_v3:smmu_evtq_event` |
| **TP_PROTO** | `struct arm_smmu_device *smmu, u64 *evt` |
| **tracefs 路径** | `/sys/kernel/tracing/events/arm_smmu_v3/smmu_evtq_event/` |
| **perf 事件名** | `arm_smmu_v3:smmu_evtq_event` |
| **trace 字段** | `iommu` (字符串), `evt0`..`evt3` (u64) |

## 3. 数据流图

```
SMMUv3 硬件                    内核驱动                        用户态
==========                    ==========                      =========

EVTQ 寄存器
   │
   ▼ (中断)
queue_remove_raw()
   │
   │  evt[0..3] = 原始数据
   │
   ├── trace_smmu_evtq_event(smmu, evt) ───► trace buffer ───► tracefs/perf
   │                                            │              / read
   │                                            │                 │
   ▼                                            │              trace-cmd
arm_smmu_handle_evt()                           │              perf record
   │                                            │
   ├── ret=0 (已处理) → continue                │
   │                                            │
   └── ret≠0 → dev_info() → dmesg              ▼
                                          (per-CPU ring buffer)
```

## 4. 实现顺序

| 步骤 | 操作 | 依赖 |
|------|------|------|
| 1 | 新建 `trace.h` | 无 |
| 2 | 在 `arm-smmu-v3.c` 中添加 `#include "trace.h"` | 步骤 1 |
| 3 | 在 `arm_smmu_evtq_thread()` 中插入 `trace_smmu_evtq_event()` | 步骤 1 |
| 4 | 编译验证：`make -j$(nproc) Image` | 步骤 1-3 |
| 5 | checkpatch 检查 | 步骤 1-3 |
| 6 | QEMU 功能验证 | 步骤 4 |

全部串行执行（总步骤少，无需并行）。

## 5. 风险点

| 风险 | 等级 | 缓解措施 |
|------|------|---------|
| `trace_smmu_evtq_event` 在中断上下文中，`dev_name(smmu->dev)` 可能触发问题 | 低 | `dev_name()` 只是返回指针，无锁、无睡眠，中断上下文安全 |
| tracepoint 在 `arm_smmu_handle_evt()` 之前，已处理事件也会被记录 | 设计意图 | 这是需求期望的行为——完整视图 |
| `__string(iommu, dev_name(smmu->dev))` 的字符串拷贝开销 | 极低 | tracepoint 本身走 __builtin_expect 的 unlikely 路径，关闭时 ~1ns |
| `#include "trace.h"` 需要 `struct arm_smmu_device` 前向声明 | 低 | trace.h 中 `struct arm_smmu_device;` 前置声明即可，include 在 .c 文件中且已在 `arm-smmu-v3.h` 之后 |
